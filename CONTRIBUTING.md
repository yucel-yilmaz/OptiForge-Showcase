# Contributing

Thanks for helping improve the OptiForge developer experience.

## Good contributions

- New synthetic examples for repeatable operational decisions
- Corrections and clearer explanations in the public API documentation
- Client reliability, accessibility, and developer-experience improvements
- Tests for reported integration behavior

Do not submit customer data, API keys, private deployment details, or content
copied from a production environment.

## Development

Use Node.js 20 or newer:

```bash
npm test
npm run check
npm run pack:dry-run
```

Open an issue before a large change. Keep pull requests focused, explain the
developer impact, and include tests when behavior changes. By contributing, you
agree that your contribution is licensed under Apache License 2.0.

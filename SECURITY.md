# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue containing exploit details, credentials, personal data, or
information about a production deployment.

Include the affected version, reproduction steps, expected impact, and any
suggested mitigation. You will receive an acknowledgement through the private
reporting thread.

## Scope

This public repository contains examples and a small API client. Reports about
the hosted OptiForge service or a private deployment should be sent through the
support channel provided with that service.
